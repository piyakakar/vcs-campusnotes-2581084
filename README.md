# CampusNotes

CampusNotes is a simple project for managing
and organizing academic notes.

## Features

- Create and manage notes.
- Organize notes by subject.
- Keep academic information organized.

## Purpose

This project is created as part of the
Version Control System assignment.
## CampusNotes Features

- Create and save personal notes.
- Organise notes using categories.
- Maintain notes in one place for easy access.
- Support collaboration through GitHub.
## Note Handling Improvements

- Display a clear message when no notes are available.
- Validate note titles before saving.
- Prevent users from saving notes with empty titles.
## How to Use CampusNotes

1. Open the CampusNotes project.
2. Create a new note.
3. Add a suitable title and content.
4. Organise the note using a category.
5. Save the note for future reference.
